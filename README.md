## Meeting with Gabriel
On Monday half of the team had our meeting with Gabriel, due to schedule conflicts. We were able to conclude that for this first iteration:
* The main function is that of an orchestra / synchronized speaker where all the user that scan with the QR code will act as speakers, while the main host will be playing the audio file.
* No complex UI will be needed for the speaker view, as their main use is to play the audio.
*  We want a Web app with chrome as the default browser but need to make sure that it works with other browsers as well.
*  The project will need a server that can handle up to 50 users and be developed mainly using JavaScript.
*  This project also aims to allow Gabriel's students to fork and modify the code for their own projects.
