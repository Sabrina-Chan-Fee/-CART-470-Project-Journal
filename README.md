## Json form
The Json form will be use for student to generate a json that will be sent to the backend. This is to avoid having the student create a json themselves, to limit the number of effects used and to avoid having typos in the json that can cause issue in the back end. We explored using some API or google forms but ended up going with plain HTML, CSS and JS for now.
