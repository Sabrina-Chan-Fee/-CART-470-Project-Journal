## Client meeting Debrief
During our meeting with Gabriel we demoed our final product, which included all the requirements he needed for the November deadline. The main deliverable were: 

- Conductor page to allows user to select what project to play and display the QR for students to join the room.
- JSON form, is fully functional, auto populated when a user uploads a json file and can download a JSON file by filling the formm.
- Phones view allows the user to be connected to a group of phones what will play the sounds. 

After our meeting with Gabriel on the 28th, we were informed that the he will be testing his own version of the distributed listening during his class. We were not aware of this other version, only that he had a "backup" plan if we didn't finish by November. 

This was a miscommunication and showed there was a need of alignments in terminology being used during meetings. We plan to better clearify and communicate future terminology and expectations in the future.   

Victoria and Eamon will be attending to gather information on how the students are using the new tool, what new feature we could add to it, what user experience can be improved and what elements are obsolete. We've decided to use Gabriel's code as a base to add the JSON form but we will also continue to improve upon our own version. We will be also adding the effects for the audio and fetching json and audio files from outside the repository.
